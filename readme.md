Cube Agent is a WIP project for a CLI tool that assists the user with solving a Rubik's Cube.

Intended Features:

- Providing computer generated scrambles. (Done)

- A timer for solves. Keeping track of agerages, personal best time, and allowing for solves to be marked as DNF and +2.

- A catalog of algorithms with visual aid for help with recognition.

- MAYBE a bot that can find the most efficient way to solve a portion of the cube (white cross, etc.) given a scramble.
